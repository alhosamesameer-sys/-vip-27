# معسلات VIP 27

موقع تعريفي عربي باتجاه RTL، مصمم للهاتف أولاً.

## محتويات الموقع
- `index.html`: الصفحة الرئيسية وأقسام من نحن والتواصل.
- `assets/shop-main.svg`: صورة من داخل المحل مضمنة داخل SVG لتسهيل استضافتها على GitHub Pages.

## بيانات يجب إضافتها قبل النشر النهائي
لم يتم اختلاق بيانات تواصل غير متوفرة. أضف:
- رقم الهاتف / واتساب.
- عنوان المحل أو رابط خرائط Google.
- ساعات العمل.
- بقية صور المحل عالية الدقة (يمكن إضافتها داخل مجلد `assets` ثم إنشاء معرض صور).

## تشغيل محلي
افتح `index.html` في المتصفح.

## النشر عبر GitHub Pages
من إعدادات المستودع: Settings → Pages، اختر النشر من الفرع `main` والمجلد `/ (root)`، ثم احفظ. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.

الموقع تعريفي فقط، ولا يحتوي على سلة شراء أو طلبات لمنتجات التبغ.
